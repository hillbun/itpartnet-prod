node_netstat_Tcp_CurrEstab      多少个 TCP 连接处于已建立（ESTABLISHED）状态
node_netstat_Tcp_ActiveOpens	主动打开的连接数	系统作为客户端发起的 TCP 连接增速。
node_netstat_Tcp_PassiveOpens	被动打开的连接数	系统作为服务端接收的 TCP 连接增速。
node_netstat_Tcp_AttemptFails	连接尝试失败次数	握手失败。值升高通常意味着网络不通或对端拒绝连接。
node_netstat_Tcp_EstabResets	已建立连接被重置次数	连接在 ESTABLISHED 状态下被强制中断（收到 RST 包）。
node_netstat_Tcp_RetransSegs	重传的数据包总数	极重要！ 衡量网络质量。值越高，丢包或延迟越严重。
node_netstat_Tcp_OutRsts	发送的 RST 包数量	本机主动重置连接的数量，可能因为端口未监听或负载过高。

#!/bin/bash
# 统计每个 IP 的连接数并输出为 Prometheus 格式
OUT_FILE="/var/lib/node_exporter/textfile_collector/tcp_conns.prom"

echo "# HELP node_tcp_connections_by_ip TCP connections count per source IP" > $OUT_FILE.tmp
echo "# TYPE node_tcp_connections_by_ip gauge" >> $OUT_FILE.tmp

# 执行你的 ss 统计命令 (假设你想统计所有已建立的连接)
ss -ant | grep ESTAB | awk '{print $5}' | cut -d: -f1 | sort | uniq -c | \
awk '{printf "node_tcp_connections_by_ip{client_ip=\"%s\"} %d\n", $2, $1}' >> $OUT_FILE.tmp

mv $OUT_FILE.tmp $OUT_FILE
