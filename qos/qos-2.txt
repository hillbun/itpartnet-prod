iftop 是 Linux 系统中非常实用的网络流量实时监控工具。它类似于 top 命令，但专注于显示网络接口的带宽使用情况，能够清晰地看到哪些 IP 正在消耗流量。

## 1. 基础用法
如果你只是想快速查看某个网卡的流量，可以使用以下命令：
默认启动（监控默认网卡）：sudo iftop
指定网卡：sudo iftop -i eth0
以字节数显示（默认是比特 Bits）：sudo iftop -B
不解析域名（直接显示 IP，速度更快）：sudo iftop -n
显示端口号：sudo iftop -P

## 2. 界面详解
在 iftop 的运行界面中，信息主要分为三个部分：
顶部： 刻度尺，显示流量密度的范围。
中间： 流量列表。每行包含源 IP（或主机名）和目的 IP。
=> 表示发送数据。
<= 表示接收数据。
最后三列分别代表：最近 2 秒、10 秒、40 秒的平均流量。

底部： 统计数据。
TX (Transmit)：发送流量。
RX (Receive)：接收流量。
TOTAL：总流量。
cum：从运行开始的累计流量。
peak：流量峰值。
rates：对应的平均值。

是的，Squid 完全可以记录服务器（即 Squid 代理自身）的 IP 地址，但在默认的日志格式中，它通常更关注客户端 IP 和目标网站 IP。

如果你需要记录 Squid 服务器自身的 IP，可以通过自定义 logformat 来实现。

如何配置记录服务器 IP
在 squid.conf 配置文件中，你可以使用 %la（Local IP address）这个宏来捕获 Squid 接收请求时的本地接口 IP 地址。

定义自定义格式：
在配置文件中添加一行 logformat。例如，我们创建一个名为 my_custom_log 的格式：

Bash
# %la 代表 Squid 服务器的本地 IP
# %tl 代表本地时间
# %client_ip 代表客户端 IP
# %ru 代表请求的 URL
logformat my_custom_log %tl %la %client_ip %ru %Ss/%03>Hs
应用该格式：
找到 access_log 指令，将其指向你刚刚定义的格式：

Bash
access_log daemon:/var/log/squid/access.log my_custom_log
生效配置：
修改后，检查语法并重新加载 Squid：

Bash
squid -k parse
squid -k reconfigure
